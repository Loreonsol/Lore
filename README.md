# LORE

**The Behavioral Intelligence Layer**

> *"Any sufficiently advanced understanding of humans is indistinguishable from empathy."*

---

## What is LORE?

LORE is a behavioral intelligence layer built on Solana. We're not building smarter AI — we're building AI that understands what smart means to a specific person at a specific moment.

While everyone else optimizes for outputs, we optimize for understanding.

---

## The Site

This repo contains the landing page for LORE — a dark, editorial, scroll-driven story built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

### Stack
- Pure HTML / CSS / JS
- Google Fonts (Playfair Display, IBM Plex Mono, EB Garamond)
- Deployed on Vercel

---

## Deployment

The site auto-deploys via Vercel on every push to `main`.

To run locally just open `index.html` in your browser — no build step needed.
